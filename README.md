# FragCheck
CS2 FACEIT Player Statistics & Performance Analytics.

Collaborative project between JoeRenDev & Kaan-Dilmen.

## Current and Planned Features

### Current Features
- FACEIT API Query
- Responsive Frontend displaying statistics
- Specific username input search

### Planned Features
**Initial features**
- Player statistics (K/D, win rate, average kills, etc)
- FaceIt ELO and skill level

**Further development**
- Player comparisons
- AI performance analysis
- AI improvement suggestions
